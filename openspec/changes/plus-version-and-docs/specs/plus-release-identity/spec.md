## ADDED Requirements

### Requirement: 增强版版本标识
系统 SHALL 使用上游版本加 `+plus.N` 标识增强版修订，N 为正整数；平台数值版本保持上游数字部分。

#### Scenario: 构建带后缀版本
- **WHEN** 构建 `2.20.0+plus.1`
- **THEN** 应用和发行文件标识包含完整后缀，Windows 数值资源和 macOS 数值版本不包含非数字字符

### Requirement: 增强版更新来源
增强版 SHALL 仅把本仓库已发布的有效增强版 Release 作为更新候选，并遵守预览开关和跳过版本设置。

#### Scenario: 上游独立发布
- **WHEN** 只有不含增强版后缀的版本或草稿发布
- **THEN** 增强版不向用户推荐该安装包

#### Scenario: 同一上游基础版本更新
- **WHEN** 当前版本为 `2.20.0+plus.1`，本仓库发布 `2.20.0+plus.2`
- **THEN** 正确提示增强版修订更新

### Requirement: 用户文档与来源归属
README SHALL 明确上游作者与仓库，区分上游基础能力和本仓库增强，提供本仓库下载与反馈入口，并区分源码能力和实际发布状态。

#### Scenario: 用户获取增强版
- **WHEN** 用户阅读 README 下载和反馈部分
- **THEN** 链接指向本仓库，通用操作文档和对上游的致谢单独标注
