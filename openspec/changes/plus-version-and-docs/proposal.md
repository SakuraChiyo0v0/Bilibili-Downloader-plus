## Why

增强版已有实际用户，但 README 主要展示上游能力，版本号和更新入口也未区分上游与 fork。用户要求保留上游基础版本、追加增强版后缀，并以专业说明呈现本仓库增量、致谢与使用指引。用户另明确授权更新检查切到本仓库 Releases。

## What Changes

- 使用 `上游版本+plus.修订号`，当前为 `2.20.0+plus.1`，与数字平台版本分离。
- 重写中英文 README，以增强功能、获取方式、使用指引、兼容差异和上游致谢为主体。
- 明确 Plus 独立维护、不向上游发起 PR，专门场景需求在本仓库演进，优先考虑稳定性、功能完整性和效率。
- 应用内增强版更新检查使用本仓库 Releases，保留上游检查实现。
- 适配后缀的 Windows、Linux、macOS 发布元数据与构建参数；不触发发布。

## Capabilities

### New Capabilities
- `plus-release-identity`: 增强版标识、版本比较、发布元数据和用户说明。

### Modified Capabilities

无。
