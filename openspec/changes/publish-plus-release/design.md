## Context

现有主分支已通过 Windows/Linux、Python 3.11/3.13 的质量检查。正式构建需要跨平台运行环境，采用仓库已有 GitHub Actions 矩阵。用户已授权本次打包、提交所需发布调整并上传 Release。

## Decisions

- 构建保持上游静态运行时和启动器方案，不另建一套打包方式。
- 签名步骤以本仓库是否具备 CERTUM_EMAIL 和 CERTUM_OTP 为条件，未签名时安装器不要求已签名卸载程序；不创建虚假签名。
- 使用手动触发先构建，再由工作流创建草稿发行；发布前验证完整产物集合、版本、可解包性和 SHA256。正式发布由本次任务核对后执行。
- 发布说明仅列本版增强、升级差异和已知限制；签名状态明确展示。
- 构建和冒烟检查使用隔离路径，不导入或改写用户真实应用配置。

## Validation

工作流语法、版本预检、跨平台构建结果、Windows 包结构与运行时冒烟、发行资产数量和 SHA256；无法覆盖的安装／平台行为如实记录。

第一次实包检查发现同步页仍引用上游已取消的控件聚合导出。新增真实页面构造测试先复现 ImportError，再改为直接导入 button 子模块；修复后重建全部产物，不发布旧草稿文件。
